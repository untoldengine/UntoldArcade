# CityStreaming

Generated by **UntoldEngine Build System**

## Overview

CityStreaming is a Vision Pro viewer for a city-scale scene that's too large to keep entirely in GPU memory. Instead of loading the whole city at startup, it streams nearby tile geometry in and out as the camera moves. It's the reference project for the [City Streaming On Vision Pro](https://untoldengine.github.io/UntoldEngine/LearningPaths/CityStreamingOnVisionPro/) learning path.

Tile stubs register immediately; nearby tiles load asynchronously at full detail; farther tiles fall back to LOD or HLOD representations; static batching updates incrementally as geometry becomes resident.

## What It Demonstrates

- `setEntityStreamScene` for loading a tiled streaming manifest instead of one monolithic model
- Distance-based tile loading/unloading, with LOD and HLOD representations for distant geometry
- Incremental static batching as streamed geometry becomes resident
- Spatial debug overlays (`setSpatialDebug(...)`) for tile bounds, octree residency, LOD levels, and texture streaming tiers
- Profiler output (`GeometryStreamingSystem.shared.getStats()` / `printStats()`) for residency, load backlog, and memory pressure
- `SpatialManipulationSystem.shared.processAnchoredSceneManipulationLifecycle` for pinch-drag and two-hand scene rotation to move through the city

## Getting Started

Open the project in Xcode:

```bash
open CityStreaming.xcodeproj
```

Select the Vision Pro Simulator or a connected Apple Vision Pro, then build and run (`Cmd+R`).

In the running app: pinch and drag to move through the city, use two hands to rotate it. Watch tiles stream in as you approach and drop to LOD/HLOD as you move away.

## Requirements

- Xcode with visionOS support
- visionOS 2.0 or later
- Apple Vision Pro device or the Vision Pro Simulator

## Asset Pipeline

This project was bootstrapped with the starter streamed-city asset pack:

```bash
untoldengine assets install starter-streamed-city
```

That installed `GameData/StreamModels/LowPolyCity/LowPolyCity.json` (the tile manifest) alongside its `LowPolyCity/` tile payload folder, which `GameScene.swift` loads via `setEntityStreamScene(entityId:manifest:"LowPolyCity", withExtension:"json")`. To use your own city, export a tiled manifest with the Blender Add-On Workflow, place it under `GameData/StreamModels/`, and update the manifest name passed to `setEntityStreamScene` — see "Replace The Starter Asset With Your Own City Scene" in the tutorial.
