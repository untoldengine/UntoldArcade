# ArchvizViewer

Generated by **UntoldEngine Build System**

## Overview

ArchvizViewer is a Vision Pro app that loads a Blender architectural visualization scene and lets you view and manipulate it in mixed reality. It's the reference project for the [Archviz To Vision Pro](https://untoldengine.github.io/UntoldEngine/LearningPaths/ArchvizToVisionPro/) learning path.

The model loads asynchronously, brings in its Blender-authored lights, camera, and color management, and can be repositioned and rotated in space with hand gestures — no scripting beyond `GameScene.swift`'s setup.

## What It Demonstrates

- `setEntityMeshAsync` for non-blocking model loading
- `loadSceneAuthored` for Blender-authored lights, cameras, and color management
- Vision Pro XR input setup (`registerXREvents`, GPU-preferred spatial picking, two-hand rotation)
- `SpatialManipulationSystem.shared.processAnchoredSceneManipulationLifecycle` for pinch-drag and two-hand scene rotation

## Getting Started

Open the project in Xcode:

```bash
open ArchvizViewer.xcodeproj
```

Select the Vision Pro Simulator or a connected Apple Vision Pro, then build and run (`Cmd+R`).

In the running app: pinch and drag to move the scene, use two hands to rotate it.

## Requirements

- Xcode with visionOS support
- visionOS 2.0 or later
- Apple Vision Pro device or the Vision Pro Simulator

## Asset Pipeline

This project was bootstrapped with the starter archviz asset pack:

```bash
untoldengine assets install starter-archviz
```

That installed `GameData/Models/Bedroom/Bedroom.untold`, the model `GameScene.swift` loads on launch. To use your own scene, export it to `.untold`, place it under `GameData/Models/`, and update the filename passed to `setEntityMeshAsync`/`loadSceneAuthored` — see "Replace The Starter Asset With Your Own Blender Scene" in the tutorial.
