# BedroomTwin

Generated by **UntoldEngine Build System**

## Overview

BedroomTwin is a Vision Pro digital twin of a bedroom: the same room model, but different parts of it behave differently at runtime. It's the reference project for the [Bedroom Digital Twin](https://untoldengine.github.io/UntoldEngine/LearningPaths/BedroomDigitalTwin/) learning path.

The room shell (walls, floor, ceiling, static furniture) renders as ordinary context geometry. The window acts as a light portal and can render as a passthrough ghost surface for mixed reality. A handful of named objects — the lamps, the door, the curtains, the laptop — stay individually selectable and carry mock digital-twin status data, so tapping one logs its state.

## What It Demonstrates

- `SceneChannel` for splitting one model into runtime categories (context geometry, a custom window channel, selectable objects)
- `registerSceneChannelPrefix("WIN_", ...)` to route window geometry into its own channel by naming convention
- A light portal (`.lightPortal(.enabled(...))`) plus passthrough ghost rendering on the window channel
- `NM_`-prefixed objects staying pickable and identity-preserved instead of being merged into batches
- Spatial tap selection resolved against mock `TwinObjectInfo` data, including handling multi-material objects that export as several `_matN` entities
- `SpatialManipulationSystem.shared.processAnchoredSceneManipulationLifecycle` for pinch-drag and two-hand scene rotation

## Getting Started

Open the project in Xcode:

```bash
open BedroomTwin.xcodeproj
```

Select the Vision Pro Simulator or a connected Apple Vision Pro, then build and run (`Cmd+R`).

In the running app: tap a lamp, the door, the curtains, or the laptop to log its mock status. Pinch and drag to move the room, use two hands to rotate it.

## Requirements

- Xcode with visionOS support
- visionOS 2.0 or later
- Apple Vision Pro device or the Vision Pro Simulator

## Asset Pipeline

This project was bootstrapped with the starter digital-twin asset pack:

```bash
untoldengine assets install starter-digital-twin
```

That installed `GameData/Models/DigitalTwin/DigitalTwin.untold`, the model `GameScene.swift` loads on launch. Its objects are pre-named for this project's channel conventions: ordinary names for the room shell, a `WIN_` prefix on the window and its glass, and an `NM_` prefix on `Table_Lamp`, `CeilingLamp_Left`, `CeilingLamp_Right`, `Door`, `Curtains`, and `Laptop`. To build this from your own room model instead, see "Replace The Starter Asset With Your Own Bedroom Scene" in the tutorial.
